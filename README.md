# Administrador de Productos - FullStack TypeScript

Aplicación web para administrar productos, desarrollada con **React**, **TypeScript**, **Vite**, **TailwindCSS** y **Node.js**.

## Características

- Listado, registro, edición y eliminación de productos
- Actualización de disponibilidad
- Validación de formularios
- Interfaz moderna y responsiva
